# Referral Module (Vue 3 + Pinia + Tailwind CSS)

A **Referral Dashboard** for users built with **Vue 3**, **Pinia**, **Tailwind CSS v3**, and **Vite**, supporting **Dark Mode**, **Mobile/Desktop**, and mock API-ready functionality.

---

## ⚡ Tech Stack

- **Vue 3** (Composition API)  
- **Pinia** (State management)  
- **Tailwind CSS v3** (Dark mode supported)  
- **Vite** (Build tool)  
- **TypeScript** (Optional/Recommended)  
- **No UI libraries** (icons only)  

---

## 🚀 Getting Started

### 1. Clone Repo
```bash
git clone https://github.com/<your-username>/referral-module.git
cd referral-module

2. Install Dependencies

npm install

3. Run Development Server

npm run dev

Open http://localhost:5173

in your browser.
4. Build for Production

npm run build

5. Preview Production Build

npm run preview
